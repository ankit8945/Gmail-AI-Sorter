# 📧 Gmail AI Sorter

Gmail AI Sorter is an AI-powered web application that helps users understand and organize their Gmail inbox automatically.  
Instead of manually opening emails, users get a clean, visual overview of their inbox using smart categorization.

## 🧠 Problem Statement

Managing a cluttered Gmail inbox is time-consuming and overwhelming.  
Important emails often get lost among promotions, updates, and social notifications.

---

## 💡 Solution

Gmail AI Sorter securely connects to Gmail and:
- Categorizes emails automatically
- Shows clear visual insights
- Helps users understand inbox patterns at a glance

---

## ✨ Key Features

- 🔐 Google OAuth 2.0 authentication
- 📥 Read-only Gmail access
- 🤖 AI-based email categorization (Gemini AI)
- 📊 Visual dashboard with insights
- 📱 Fully responsive (mobile & desktop)
- 🔒 Privacy-first design (no permanent email storage)

---

## 🛠️ Tech Stack

**Frontend**
- React
- Tailwind CSS
- Deployed on Vercel

**Backend**
- Node.js
- Express
- Deployed on Render

**APIs & AI**
- Gmail API (read-only)
- Gemini AI

---

## 🔄 Application Flow

1. User logs in with Google
2. Gmail API fetches email metadata (read-only)
3. Gemini AI categorizes emails
4. Processed insights are shown on the dashboard
